# Account Management System

## 📌 Project Description

The **Account Management System** is a simple Java console-based project. It allows the user to enter account details, deposit money, withdraw money, and view the current account balance.

This project is useful for beginners to understand **Java methods, variables, Scanner class, conditional statements, and basic arithmetic operations**.

## ✨ Features

* Enter account holder name
* Enter account number
* Enter initial balance
* Deposit money
* Withdraw money
* Check sufficient balance before withdrawal
* Display current account details
* View current balance

## 🛠️ Technologies Used

* **Java**
* **Scanner Class**
* **OOP Concepts**
* **Conditional Statements**
* **Methods**

## ▶️ How to Run

1. Install Java JDK on your computer.
2. Open the project in VS Code, IntelliJ IDEA, Eclipse, or any Java-supported IDE.
3. Save the file as:

```text
AccountManagementSystem.java
```

4. Compile the program:

```bash
javac AccountManagementSystem.java
```

5. Run the program:

```bash
java AccountManagementSystem
```

## 💻 Working

The program performs the following steps:

1. Takes the account holder's name.
2. Takes the account number.
3. Takes the initial balance.
4. Takes the deposit amount and adds it to the balance.
5. Takes the withdrawal amount.
6. Checks whether sufficient balance is available.
7. Displays the account details and current balance.
